# Современное React Todo Приложение

Красивое и функциональное приложение для управления задачами, построенное на React, TypeScript и Tailwind CSS. Это приложение предоставляет чистый и интуитивно понятный интерфейс для управления вашими ежедневными задачами.

![Скриншот Todo приложения](https://images.unsplash.com/photo-1484480974693-6ca0a78fb36b?auto=format&fit=crop&q=80&w=2072)

## Особенности

- ✨ Чистый и современный интерфейс
- ✅ Создание, выполнение и удаление задач
- 🎯 Отметка задач как выполненных/невыполненных
- 🎨 Красивый градиентный фон
- 📱 Полностью адаптивный дизайн
- 🚀 Быстрый и легкий
- 💪 Построен с использованием TypeScript для безопасности типов

## Технологический стек

- [React](https://reactjs.org/) - JavaScript библиотека для создания пользовательских интерфейсов
- [TypeScript](https://www.typescriptlang.org/) - JavaScript с синтаксисом для типов
- [Tailwind CSS](https://tailwindcss.com/) - CSS фреймворк, основанный на утилитах
- [Vite](https://vitejs.dev/) - Инструментарий нового поколения для фронтенда
- [Lucide React](https://lucide.dev/) - Красивые и согласованные иконки

## Начало работы

### Предварительные требования

- Node.js (версия 16 или выше)
- npm или yarn

### Установка

1. Клонируйте репозиторий
```bash
git clone https://github.com/yourusername/modern-react-todo.git
```

2. Перейдите в директорию проекта
```bash
cd modern-react-todo
```

3. Установите зависимости
```bash
npm install
```

4. Запустите сервер разработки
```bash
npm run dev
```

5. Откройте браузер и перейдите по адресу `http://localhost:5173`

### Сборка для продакшена

Для создания продакшен-сборки:

```bash
npm run build
```

Собранные файлы будут находиться в директории `dist`.

## Использование

- Добавляйте новую задачу, введя текст в поле ввода и нажав Enter или кнопку Плюс
- Отмечайте задачу как выполненную, нажав на иконку круга
- Удаляйте задачу, нажав на иконку корзины
- Задачи хранятся в памяти браузера
